# K3 datasets

This directory contains the six datasets consumed by `run_all.py` and
`run_ablation.py`:

- `UAVSwarm-10-k3`
- `UAVSwarm-48-k3`
- `count3_k3`
- `count2_k3`
- `uavswarm61_k3`
- `watercraft_k3`

The runtime scripts read each sequence's detection and ground-truth files
directly from this directory. The image files are stored with Git LFS.

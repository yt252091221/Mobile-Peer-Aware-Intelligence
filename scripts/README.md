# Runtime scripts

Only scripts used by the final reproduction entrypoints are included here.

- `run_ours_k3_paper_formula_weight_sweep.py`: Ours runner used by the main
  comparison.
- `run_boxmot_k3.py`: ByteTrack, BotSort, and StrongSORT runner.
- `run_deepsort_k3.py`: local DeepSORT runner.
- `run_ours_k3.py`: Ours runner used by the separate ablation entrypoint.

Plotting, historical backup, and exploratory weight-sweep scripts are not part
of the GitHub reproduction package.
